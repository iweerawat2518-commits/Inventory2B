BUENGNIAM SMART INVENTORY

ระบบบริหารวัสดุคงคลัง โรงพยาบาลส่งเสริมสุขภาพตำบลบึงเนียม

ยังไม่ได้ตั้งค่าการเชื่อมต่อ Backend

ไฟล์นี้ถูกเปิดจากเครื่อง (HTML Standalone) แต่ค่า GAS_API_URL ยังไม่ถูกต้อง
  1. ใน Apps Script เลือก Deploy > New deployment > Web app
  2. Execute as: Me / Who has access: Anyone (จำเป็นสำหรับการเรียกจากไฟล์ในเครื่อง)
  3. คัดลอก Web app URL ที่ลงท้ายด้วย /exec
  4. เปิดไฟล์ index.html ด้วย Text Editor แล้วแก้บรรทัด const GAS_API_URL = "..."
  5. บันทึกไฟล์แล้วเปิดใหม่
ทางเลือกที่แนะนำสำหรับใช้งานจริง: เปิดระบบผ่าน URL ของ Web App โดยตรง (Apps Script HTML Service) ซึ่งไม่ต้องตั้งค่า GAS_API_URL — ดูคู่มือ README.md
